# 🪪 Digital Networking Card (Carte Numérique)

A responsive, interactive digital networking card built as a modern alternative to a classic CV for networking events and professional meetups. 

## 📌 About the Project

This project was developed as an academic mini-project to demonstrate foundational web development skills. The core objective and strict constraint of this assignment was to build a complete, visually appealing interface **using strictly HTML5 and CSS3**, without the use of JavaScript or any external CSS frameworks (like Bootstrap or Tailwind). 

It serves as a lightweight, highly accessible digital portfolio showcasing personal branding, technical skills, and contact information.

## 🛠️ Built With

* **HTML5:** Semantic structuring (`<header>`, `<main>`, `<section>`, `<footer>`) for better accessibility and SEO.
* **CSS3:** Custom styling utilizing CSS variables (`:root`), Flexbox for dynamic layouts, the Box Model, and pseudo-classes for interactive hover states.

## ✨ Features

* **100% Vanilla:** Zero JavaScript and zero external dependencies.
* **Responsive Design:** Fluid layout that adapts smoothly to both mobile devices and desktop screens.
* **Custom UI Elements:** Skill progress bars and layout grids built purely from scratch using CSS.
* **Performance:** Extremely lightweight, ensuring instantaneous load times.
